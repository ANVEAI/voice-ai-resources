# Contributing Guidelines

Thank you for your interest in contributing! 🎉

## How to Contribute

### Adding Resources

1. **Ensure the resource is voice AI related**
2. **Check for duplicates** — search before adding
3. **Follow the format** — maintain consistent formatting
4. **Add to the appropriate section**
5. **Submit a pull request**

### Format

Use this format when adding resources:

```markdown
| Resource Name | Brief description | Pricing/Size | Link |
```

### Categories

- Speech-to-Text (ASR)
- Text-to-Speech (TTS)
- Voice Cloning
- Conversation AI
- Voice Analytics
- Real-time Voice
- Voice SDKs & APIs
- Open Source Models
- Datasets
- Learning Resources
- Deployment & Infrastructure

### Quality Standards

Please ensure resources:
- Are actively maintained
- Have clear documentation
- Are accessible (open source or have public pricing)
- Are relevant to voice AI

### Updating Existing Resources

If you find outdated information:
1. Update the relevant entry
2. Explain the change in your PR description

### Removing Resources

Resources may be removed if they:
- Are no longer maintained
- Are no longer accessible
- Violate terms of service

## Code of Conduct

- Be respectful and constructive
- Focus on quality over quantity
- Help others learn and improve

## Questions?

Open an issue if you have questions about contributing.

Thank you for contributing! 🚀
